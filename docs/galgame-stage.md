# Galgame 多人舞台

多人聊天中点击「打开 Galgame 舞台」。桌面端在当前显示器全屏显示，窗口没有系统标题栏；退出全屏后可用顶部移动按钮和边缘拖动调整桌面位置、尺寸。收起舞台恢复原来的桌宠窗口。

## 使用

- 底栏：角色、背景、灯光、布局、历史、更多。空闲 3.2 秒淡出，移动鼠标或键盘操作恢复。
- 编辑布局：拖动角色，滚轮调整角色大小；Ctrl＋滚轮缩放整个画面；空格＋拖动平移。观看状态锁定拖拽。
- 布局中有全身/半身构图、自动排列、画面复位和命名场景保存。场景包含背景、站位、角色显隐、画面缩放和灯光；载入场景不修改正在进行的对话参与者。
- 背景支持内置场景、透明桌面、本地 PNG/JPEG/WebP（20 MB、4000 万像素以内）、铺满/完整显示、裁切位置、亮度和模糊。上传后保存在后端用户数据目录，不依赖原图路径。
- 灯光支持共同光照和独立角色外观；舞台共同光照优先于角色主光/补光。弹窗即时预览，应用保存，取消恢复。角色设置页通过「调整灯光…」打开同一组件，并提供独立模型预览。
- 更多中可隐藏对话框、隐藏界面、保存不带 UI 的 PNG 截图、窗口置顶，以及打开语音设置和多人对话管理。
- `H` 隐藏/恢复界面；`F11` 切换全屏；`Esc` 依次关闭灯光弹窗/面板、恢复隐藏界面、退出编辑、退出全屏。
- 对话框复用多人聊天的队列，支持选择说话对象、发送消息和打断。多人聊天窗口是队列所有者，桌面端将其隐藏后仍可正常接收舞台操作；浏览器使用时需要保留该页面。

## 边界

- `stageScene.ts`：场景数据和存储校验；图片只保存资源引用，文件落在 `.local/stage-backgrounds`（相对于 `paths.data`）。
- `StageControls`：舞台 UI，`DesktopPet`：演员及共享渲染器，`LightingDialog`：临时预览与提交。
- `stageMeetingBridge`：跨窗口命令和确认，不拥有 LLM、语音或讨论调度；`MeetingPage` 继续作为唯一队列所有者。
- `set_desktop_stage_mode`：保存/恢复桌宠窗口几何，并切换当前屏幕全屏。`stageWindow`：前端窗口操作。
- `fitStageCamera`：按模型包围盒构图，半身缩放保持头部可见；普通桌宠继续使用原来的脚部锚定缩放。

## 验证

```sh
npm run typecheck
npm test
npm run build
node scripts/verify-stage.mjs
cargo check --manifest-path src-tauri/Cargo.toml
npm run verify:desktop -- --skip-chat
```

浏览器验证使用独立上下文、5197 端口和 `.local/stage-verification` 下的上传目录，不读写用户对话，不调用真实 LLM。覆盖背景上传、场景恢复、灯光应用/取消、角色显隐、跨窗口邀请/移出、截图和设置预览。桌面烟雾验证检查打包启动与接口；真实语音回复需使用已配置的 LLM/TTS 验收。
