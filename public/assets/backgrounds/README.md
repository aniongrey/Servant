# 设置壁纸

`sakura-settings-1080p.png` 是 1920×1080 的粉色二次元壁纸。
在「系统设置 → 界面主题」选择「樱梦 / Sakura」启用壁纸及配套粉紫配色；主题会保存在本地设置中。

可以用自己的 PNG 同名覆盖，开发版刷新页面后生效；打包版需重新构建。
配色变量位于 `src/ui/user-interface.css` 的 Sakura 区段。

使用内置 ImageGen 生成，并以浏览器 Canvas 导出精确 Full HD 尺寸。
最终提示：参考用户图片的梦幻粉紫天空与云朵风格；粉色为主，人物、月牙、水晶阶梯与复杂图形仅位于右下角，上方和左侧保持柔和粉色留白；无文字、边框或水印。
