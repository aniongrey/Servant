### 踩到的坑

- **early return + hooks**：`TtsVoiceLibrary` 一开始把 `if (!supported) return null` 放在 `useMemo` 之前，供应商从 openai 切到 microsoft 就会
  钩子数量变化直接抛错。`renderToStaticMarkup` 单次渲染**测不出这个**（三种 provider 的渲染断言全绿）。
  规矩：所有 hook 提到早退之前，早退只留最后一个。
- **静态预览必须带布局外壳**：`.aurelia-frame` 是 `218px minmax(0,1fr)` 栅格，探针漏掉 `<aside class="aurelia-sidebar">`，
  面板被挤进 218px 第一列 → 截图里名字全截断、按钮溢出，差点当回归去改样式。补侧栏 + 空的 `.aurelia-character-controls` 后同款 CSS 正常。
- **prettier 全仓本来就红（368 文件）**，不能当门禁：工作区 EOL 是混合的（新建文件 LF、就地编辑的老文件 CRLF），
  且 `docs/architecture.md` 在 HEAD 上就不过。判定法＝复制到 `.local/triage/pf/<原路径>` 归一成 LF 再 `prettier --check`，
  `git show HEAD:` 出来跑同样的检查可证明「这条红是既有的」。本次真格式问题 7 个文件，已写回。
- 新 CSS 类不会自动继承浅色主题：得同时加进 `:is([data-theme='moonlight'],[data-theme='sakura'])` 那份长选择器清单，并把
  `:first-child` 之类的结构选择器换成显式类名（`.aurelia-asset-library-main/-copy`）。用 5 行脚本抽类名逐个 grep，一次查出漏定义。
- `Edit` 偶尔报 `EBUSY: resource busy or locked`（文件被外部工具/索引占用），重试同一条即可。
